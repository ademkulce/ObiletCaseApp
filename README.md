# Obilet Bilet Sorgulama Uygulaması 

Bu proje, Obilet API kullanılarak geliştirilmiş responsive bir otobüs bileti arama uygulamasıdır.  
Kullanıcılar kalkış ve varış noktalarını seçerek tarih bazlı otobüs seferlerini sorgulayabilir.

## Teknolojiler
- ASP.NET Core MVC (.NET 6/7/8)
- Razor View + Responsive HTML/CSS
- JSON API Entegrasyonu
- localStorage kullanımı
- Modal detay gösterimi
- Mobil uyumlu tasarım

## Öne Çıkan Özellikler
- Aynı şehir seçimi engellenir
- Şehirleri değiştirme (🔁)
- Bugün/Yarın hızlı tarih seçimleri
- Seçili bilgiler sayfa yenilense bile korunur
- Sefer detayları modal olarak gösterilir

##  Demo
Proje çalıştırıldığında ana sayfada kalkış/varış seçip seferleri listeleyebilirsiniz.

##  Kurulum
1. Bu repoyu klonlayın
2. Visual Studio ile açın
3. Gerekirse `appsettings.json` ya da startup konfigürasyonlarını kontrol edin
4. F5 ile çalıştırın 🚀
